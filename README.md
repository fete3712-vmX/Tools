## Notes

- **100% Client-Side:** No files, tokens, or personal data are stored or sent to custom backend servers.
- **Free & Open Source:** Zero tracking, zero ads.
- **PWA & Offline Support:** Core application shell and standalone tools work offline. Tools relying on external APIs or CDNs require an internet connection.
